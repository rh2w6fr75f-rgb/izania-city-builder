# Izania

A browser-based city-building game. Open `index.html` to play locally, or use the public GitHub Pages link once it is enabled.

## Play

Choose a building, drag across the map to paint a plan, review the materials and costs, then confirm. The construction queue builds in order as treasury, timber, and stone become available. Realm Messages records construction, newly discovered civilizations, war results, and royal events.

## Testers

Download `Izania-Playtest.zip`, extract it, and open `index.html` in a desktop browser. Saves are local to each tester's browser and device.

## Publishing

Every push to `main` runs the GitHub Pages workflow and publishes the current `index.html`. Use `update-and-publish.ps1` after changing the game to refresh the tester ZIP, commit, and push the update.
