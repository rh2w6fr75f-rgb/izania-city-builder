IZANIA — PLAYTEST BUILD

How to play
1. Extract this ZIP file.
2. Open index.html in a modern desktop browser (Chrome, Edge, or Firefox).
3. Choose a building, then drag across the terrain to paint a construction plan.
4. Review the list and costs, then confirm. Builds run in order as treasury, timber, and stone become available.
5. Check Realm messages for new civilizations, construction updates, and war events.

Notes for testers
- Your save stays in this browser on this device.
